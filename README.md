# Individualized ECG waveform forecasting

![Framework overview](assets/fig1.png)

A generative AI-ECG framework for modelling how ECG morphology evolves from an individual's baseline. It translates cross-sectional age-associated structure into individualized waveform trajectories that can be inspected, measured and tested against follow-up ECGs.
